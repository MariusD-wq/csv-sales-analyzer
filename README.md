# CSV Sales Analyzer

A small sales analysis project built with Python and pandas. Load sales data from a CSV file, calculate revenue for each row from quantity and price, and display total revenue alongside the updated sales data.

Built to practice Python fundamentals, CSV file handling, data manipulation with pandas, and automated testing with pytest.

## Features

- Load sales data from a CSV file into a pandas DataFrame.
- Calculate revenue for each row by multiplying quantity by price.
- Calculate total revenue across all sales.
- Display the updated sales data and total revenue in the terminal.
- Includes sample sales data and unit tests for revenue calculations.
